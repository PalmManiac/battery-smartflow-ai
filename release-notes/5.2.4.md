# Brief native sensor interruptions

Short ZenSDK communication gaps no longer make native Zendure hardware sensors flicker immediately to unavailable. The portal briefly keeps the last valid display value for up to five seconds and marks it with the `display_stale` attribute. If the interruption lasts longer, the sensor becomes unavailable as before.

This is a presentation-only grace period: control decisions and internal freshness checks continue to use current measurements, so the retained value is not used for regulation.

Restart Home Assistant after installing the update.
