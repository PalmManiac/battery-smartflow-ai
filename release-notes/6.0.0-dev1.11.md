# Battery pack identification by serial suffix

This test build adds the final four alphanumeric characters of each battery pack's serial number to its numbered label in Home Assistant and in the portal hardware overview. The portal receives only this shortened suffix. Existing pack numbering and device identifiers stay the same.

## External field tests requested

- On a system with several battery packs, confirm each Home Assistant battery-pack device name shows its pack number and the final four serial characters when available.
- Confirm the portal hardware overview shows the same pack number and suffix directly on each battery card, without opening its details.
- For a system with many packs, such as ten, check whether the visible suffixes make the packs easy to distinguish and whether any suffixes are duplicated.
- Confirm packs without a usable serial number still appear with their existing numbered labels.
- After restarting Home Assistant or reloading the integration, confirm the pack labels remain consistent and the sensors continue to update.
- Report the exact BSFAI version, Home Assistant version, hub model, number of packs, and any missing or duplicate suffixes. Sanitize screenshots and diagnostics so full serial numbers, credentials, and private details are not exposed.

We will review external reports before starting the next development stage.
