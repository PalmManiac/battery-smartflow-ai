# Configurable Zendure standby behavior

This release adds a setting for Zendure Smart Mode standby behavior.

## Improvements

- Keep `smartMode=1` during idle by default on devices and communication paths that support direct Smart Mode writes.
- Change this behavior from the Home Assistant integration options or the BSFAI Portal. When disabled, the existing model-specific standby behavior is used. ([PR #799](https://github.com/PalmManiac/battery-smartflow-ai/pull/799))

## After updating

Restart Home Assistant after installing the integration.
