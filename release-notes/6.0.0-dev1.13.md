# Per-system communication path reporting

This test build displays each Zendure system's own configured communication path in its Home Assistant hardware overview. Previously, a secondary system could display the Cloud discovery path even when ZenSDK had been selected for that system.

## External field tests requested

- Confirm that the communication path sensor for every system matches the path selected for that system, including when different systems use different paths.
- In a multi-system setup, confirm that changing which system is selected for control does not change the other systems' displayed paths.
- Reload the integration or restart Home Assistant and confirm the displayed paths still match the saved per-system choices.
- Report the exact BSFAI version, system names or models, selected path per system, and whether each displayed value is correct. Please sanitize screenshots and diagnostics before sharing.

We will review external reports before moving on from this dev1 test stage.
