# V6.0.0-dev1: Multi-device discovery and setup

This pre-release starts field validation of the V6 native Zendure device inventory.

- Discover and configure each supported main system separately.
- Save the selected communication path per device, including mixed transports in one account.
- Keep temporarily missing devices in the inventory and unsupported devices read-only.
- Keep native write control limited to the existing single selected system. Multi-device power regulation is not enabled.

## External field tests requested

Please test accounts with two or more Zendure main systems, including mixed models and transports, several battery packs, offline/reconnected devices, and Home Assistant restart or integration reload. Confirm that device and pack identities remain correctly assigned, that the selected path is observed for each system, and that unsupported devices remain read-only.

Please share the sanitized BSFAI diagnostic export and a short report of the models, selected paths, and any unexpected behavior. Do not include account credentials or App-Tokens.
