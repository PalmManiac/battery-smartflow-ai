# Electrical Topology for Multi-System Installations

This development release adds a separate configuration model for the physical electrical installation. It can describe phases, circuits, shared upstream circuits, optional current and power limits, Zendure grid/off-grid outputs, and grid or off-grid load domains. The portal displays the saved topology and opens its editor; the Home Assistant OptionsFlow uses the same saved configuration.

No default 16 A or 3680 W limit is assumed. Topology configuration is currently descriptive and diagnostic; it does not change battery regulation or enforce the entered limits.

## External field tests requested

- Configure devices on the same phase and the same circuit, then on the same phase but separate circuits.
- Configure devices across different phases and confirm each circuit shows the intended phase.
- Add a shared upstream circuit with its own limit and confirm the portal shows the hierarchy.
- Leave current or power limits empty where no configured limit is known; confirm no implicit limit appears.
- Map grid-connected outputs and separate off-grid/UPS outputs into their respective load domains.
- Confirm topology changes are visible in both the portal and the Home Assistant OptionsFlow and survive a Home Assistant restart.
- Confirm regulation behavior is unchanged by topology configuration. Send the installation shape, Home Assistant/browser versions, screenshots and sanitized logs with any issue.
