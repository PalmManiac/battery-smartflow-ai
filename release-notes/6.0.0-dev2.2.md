# Zendure model images in battery group cards

This development update adds a small product image to each recognized Zendure system in the Battery Groups view. The image is shown beside the system details and uses the same model mapping as the hardware topology view. Unknown models retain the existing text-only card.

## External field tests requested

- Open Battery Groups and confirm the image matches each system model and appears beside that system's details.
- If multiple systems or models are available, confirm each card shows the correct image independently.
- Check the view on a narrow or mobile screen and confirm the image and text remain readable.
- If a supported model has no image, the wrong image appears, or the card layout breaks, report the displayed model, approximate screen size, and a screenshot with private identifiers removed.
