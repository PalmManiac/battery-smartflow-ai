# Portal settings show saved values

This maintenance release fixes missing current values in the BSFAI Portal settings.

## Fixes

- Prefill the General and Expert Mode forms with the saved Home Assistant option values, so settings are visible and are not accidentally changed when saving. ([PR #802](https://github.com/PalmManiac/battery-smartflow-ai/pull/802))

## After updating

Restart Home Assistant after installing the integration.
