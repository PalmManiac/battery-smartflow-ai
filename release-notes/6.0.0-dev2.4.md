# Reliable Zendure Off-Grid Mode Selection

This development update fixes native Zendure off-grid mode changes that could fail with `property_not_allowed`. A mode-only request is now kept separate from the automatic zero-power stop sequence, so changing the off-grid mode does not add unrelated charge or discharge properties.

## External field tests requested

- Change the off-grid mode while the battery system is idle. Confirm the selection is accepted and the Home Assistant entity reflects the selected mode.
- Repeat while charging and while discharging, if safe and practical in your setup.
- Confirm that changing the off-grid mode does not unexpectedly change charge or discharge mode, power limits, or current operation.
- Report any failed selection or unexpected power change with the device model, transport, operating state, and a sanitized diagnostic log.
