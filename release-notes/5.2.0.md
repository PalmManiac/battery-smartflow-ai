# More precise control and clearer energy flows

This release adds passive regulation training, clearer energy-flow diagnostics, and reliability improvements for grid measurements and Zendure communication.

## Highlights

- Add optional passive regulation training for charge, discharge, or both directions for up to 24 hours. Review sample coverage, response estimates, confidence, and overshoot before deciding whether to apply a candidate. Candidates are never applied automatically and remain scoped to the device and transport used for training.
- Add reversal-hysteresis shadow evaluation for eligible automatic decisions, including PV-driven decisions in Autarky mode. This is simulation and analysis only: **the active regulation is not delayed or changed by the shadow evaluation**. An actively enforced reversal lock is deferred until real-world data has been validated and will be delivered separately.
- Redesign the dashboard energy overview as a live flow diagram, including direction-aware flows, detected AC battery charging, a single home node, and smoother battery and energy-flow animations. The diagram shows measured readings and does not invent direct PV-to-battery or grid-to-battery paths.
- Improve Zendure Smart Mode handling: active charge and discharge commands use Smart Mode 1; standby behavior is selected by device model when off-grid output is confirmed to be zero. For the SF2400 AC, standby uses Smart Mode 0; other currently supported property-controlled models use Smart Mode 1. Unknown or active off-grid output keeps Smart Mode 1. This behavior is based on field reports, not an official Zendure compatibility specification.
- Improve regulation response to fresh Shelly grid readings, handle short grid-sensor gaps more safely, and add optional Modbus TCP for the Shelly Pro 3EM Gen2 with total and per-phase readings. Modbus must be enabled on the Shelly first; the Shelly 3EM Gen1 continues to use local HTTP.
- Refine price-reserve priorities, training-data classification, dashboard settings and diagnostics, hardware topology labels, and the regulation-training guide.

## Known limitation

- The SF800 Pro pass-through behavior near full battery state from [Issue #774](https://github.com/PalmManiac/battery-smartflow-ai/issues/774) remains under investigation and is not fixed by this release.

## After updating

Restart Home Assistant after installing the integration. Reload the dashboard if it was already open during the update.
