# Persistent groups for Zendure systems

This test build adds a persistent group model for configured Zendure systems. Groups can be created, renamed, removed, and reorganized in the Home Assistant OptionsFlow or the Battery SmartFlow AI portal. Both interfaces use the same saved configuration. Existing configured single-system installations migrate to a matching group; newly discovered systems remain ungrouped until assigned, and saved memberships remain when a system is temporarily offline.

This release does not add power regulation across multiple systems. The group settings describe system membership only.

## External field tests requested

- Check one configured system in one group and confirm the group name and membership survive a Home Assistant restart and integration reload.
- If available, check two to four configured systems in one group, then create multiple groups. Confirm the portal and Home Assistant OptionsFlow show the same memberships.
- Move a system between groups and confirm it belongs to no more than one group after saving and reloading.
- Temporarily take a grouped system offline. Confirm it remains in its group, then confirm it returns to its normal displayed state when it reconnects.
- Add or discover another system after creating groups. Confirm it remains ungrouped until you assign it.
- Report any missing or duplicated systems, unexpected membership changes, or portal/OptionsFlow differences. Include the approximate time and screenshots or diagnostics with App Tokens, serial numbers, network addresses, and other private identifiers removed.

Please do not expect or test simultaneous power regulation of multiple systems in this development release.
