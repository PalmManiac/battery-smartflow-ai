# V6.0.0-rc4 – Technische Fehler im Gruppendialog lesbar anzeigen

Diese Release Candidate verbessert die Fehleranzeige beim Öffnen der Portal-Konfiguration:

- Strukturierte Home-Assistant-API-Fehler werden lesbar im Dialog dargestellt, statt als `[object Object]`.
- Dadurch werden Status, Meldung und weitere verfügbare Fehlerdetails für die Diagnose sichtbar.

Bitte die Aktionen **Gruppe anlegen**, **Gruppe bearbeiten** und **Gruppe entfernen** erneut testen. Falls ein Dialog nicht startet, kopiere die vollständige technische Meldung aus dem Dialog in deine Rückmeldung.

Dies ist eine Release-Candidate-Version für externe Tests.
