# Battery SmartFlow AI 5.1.0-beta10

This beta corrects the current battery state-of-charge reading on the HEMS
dashboard.

## Changes

- Prefer the configured current SoC sensor when it is a real charge-level
  reading, while excluding minimum/maximum limits and other SoC boundary
  entities.
- When the configured source is a limit, resolve a system-level current SoC
  sensor such as the device's live state-of-charge or charge-level sensor
  before considering individual battery-pack readings.
- Bump the dashboard asset version to 1.0.12 and refresh its cache key.

## Testing focus

Please compare the dashboard battery percentage with the live system
state-of-charge sensor and confirm it no longer shows the hardware minimum SoC.
