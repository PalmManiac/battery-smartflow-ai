# V6.0.0-dev1.4: Multi-system battery power in the dashboard

This dev1.04 test build uses the native charge and discharge measurements from all discovered Zendure systems for the dashboard's combined battery power when a BSFAI entry contains multiple systems. Single-system installations keep using their configured battery power sensor. The control path remains limited to the selected system; coordinated multi-system control is not included.

## External field tests requested

- Upgrade from dev1.3 to dev1.4 and confirm the dashboard battery power includes every discovered system while charging and discharging.
- Confirm the reading remains available after a Home Assistant restart and report the models, BSFAI version, and selected control path.
- Check whether the dashboard's house-consumption reading is present. If it is missing, attach a screenshot and provide the current entity states for the configured grid, PV, battery, and house-load sensors.

The house-consumption display is still under investigation; this test build does not claim to fix it. Please do not publish credentials, App-Tokens, or private system details with reports.
