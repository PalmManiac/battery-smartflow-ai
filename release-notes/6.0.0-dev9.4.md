# V6.0.0-dev9.4 – Gruppen-Konfiguration an einem Ort

Diese Testversion bündelt die Einrichtung von Sensorzuordnung und elektrischer Topologie im Gruppenassistenten:

- Die separaten Schalter für Sensorzuordnung und elektrische Topologie entfallen im Portal.
- Beim Anlegen oder Bearbeiten einer Gruppe führst du die Konfiguration weiterhin Schritt für Schritt im Assistenten durch.
- Die Gruppenübersicht zeigt Sensorzuordnung und Topologie weiterhin an und weist auf den Gruppenassistenten zum Ändern hin.
- Die direkten Einstiege im Zahnrad-Menü bleiben für bestehende Konfigurationen verfügbar.

Bitte das Anlegen und Bearbeiten von Gruppen prüfen, insbesondere die Schritte für Topologie und Sensorzuordnung sowie die anschließende grafische Anzeige in der Übersicht.

Dies ist eine Entwicklungsversion für externe Tests.
