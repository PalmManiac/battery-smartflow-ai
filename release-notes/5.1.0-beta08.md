# Battery SmartFlow AI 5.1.0-beta08

This beta adds Recorder long-term statistics to the dashboard's week and month
history charts. Hour and day views continue to use recorded entity states.

## Changes

- Use Home Assistant long-term statistics for week and month history when the
  selected entity has statistics, with the existing state-history request as a
  fallback.
- Render counter statistics from their per-period change values and use hourly
  points for weeks and daily points for months.
- Avoid displaying a hardware SoC limit as the current battery charge; if a
  configured dashboard source points to a limit, resolve a current SoC sensor
  from its state-of-charge/charge-level name instead.
- Bump the dashboard asset version to 1.0.9 to refresh cached clients.

## Testing focus

Please verify hour and day views still work, and that week and month charts now
show the available Recorder history for both measurement and energy-counter
sensors. Entities without long-term statistics should retain the ordinary
history fallback.
