# Localized Sensor Assignment Labels

The EnergyScope configuration is now presented as sensor assignments in the Home Assistant options flow and HEMS portal. Labels follow the configured language in German, English, French, and Dutch. Forecast sources and price context remain part of the assignment; configuration behavior is unchanged.

## External field tests requested

- Confirm the settings menu, create/edit/remove actions, and portal button use the expected language for your Home Assistant language setting.
- Check that the sensor assignment screens remain understandable and that existing group, grid, PV, forecast, and price selections are still shown and saved correctly.
- Verify that the portal and gear-menu options refer to the same assignments.
- Report the Home Assistant language, browser/device, screenshots, and a sanitized diagnostic log if labels are missing, appear in the wrong language, or any configuration changes unexpectedly.
