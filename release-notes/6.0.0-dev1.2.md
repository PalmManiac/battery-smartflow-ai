# V6.0.0-dev1.2: ZenSDK fixed-address support

This dev1.02 test build adds an optional per-device private IPv4 address for native ZenSDK communication. When configured, BSFAI uses that address directly for the device and bypasses mDNS discovery. Invalid saved addresses fail closed. Existing per-device polling and retry behavior is preserved.

## External field tests requested

- Configure a valid fixed IPv4 address for one ZenSDK device and confirm its setup remains saved after a Home Assistant restart.
- Confirm that device continues to provide telemetry and that other devices using their existing communication paths remain unaffected.
- Confirm that an invalid address is rejected or safely prevents communication for that device rather than silently selecting an unintended address.

This release includes the fixed-IP support from PR #830 for Issue #811. It does not claim to fix the separate intermittent portal and entity unavailability reported in Discussion #826; that report remains under investigation. Coordinated control of multiple systems is not included in dev1.

Do not publish account credentials or App-Tokens with diagnostic reports.
