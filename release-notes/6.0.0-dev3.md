# Group-Aware Energy Sources for Multi-System Setups

Dev3 introduces EnergyScopes to connect battery groups with the grid measurements, PV power sensors, forecast providers, and price sensors that describe their energy system. It supports signed grid readings (including separate phase sensors), split import/export readings, multiple PV sources, and forecast-to-PV mapping. The portal and Home Assistant options flow show and configure these assignments. This release configures measurement and forecast contexts; it does not enable productive multi-battery regulation.

## External field tests requested

Please test with representative multi-system configurations and report screenshots plus a sanitized diagnostic log:

- One PV system with several battery systems in a group.
- Multiple PV systems with the same orientation, and PV systems with different orientations such as east, west, and south.
- Multiple forecast providers, each mapped to the PV system it describes. Confirm that forecasts are not counted twice.
- One shared P1 meter and, if available, multiple P1 meters assigned to separate groups.
- Signed total grid power, signed per-phase sensors, and split import/export sensors.
- In the portal and options flow, create, edit, and remove EnergyScopes; assign groups and verify that a group cannot be assigned to two scopes.
- Confirm that reported grid and PV power matches Home Assistant values and that missing or unavailable source sensors are clearly reflected without silently mixing in another system's measurements.

Include the battery models, group layout, sensor types, PV orientations, forecast integrations, and whether grid sensors are signed or split. Please do not enable or expect multi-battery control in this development release.
