# Keep Hyper battery pack inventory stable during sparse updates

This test build improves Hyper pack inventory handling when Zendure reports only part of the pack data in an update. A sparse report should no longer make a confirmed multi-pack system appear to have fewer packs. The inventory can still reflect a genuine, confirmed pack change.

## External field tests requested

- Hyper owners, especially those with mixed AB2000S and AB2000X packs: confirm that all configured packs remain visible and that the reported total capacity remains consistent during normal operation.
- Watch for inventory or capacity changes after a Home Assistant restart and during periods when telemetry updates are sparse. Please report whether any pack disappears temporarily or stays missing.
- If a mismatch occurs, capture the approximate local time, the visible pack count and capacity, the BSFAI version, and a debug recording covering the event. Do not share App Tokens, serial numbers, network addresses, or other private identifiers.

We will review external reports for this dev1 test build before advancing to the next development issue.
