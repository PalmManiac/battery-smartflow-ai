# V6.0.0-rc6 – Portal-Aktionen im Optionsflow freigeben

Diese Release Candidate korrigiert die Weiterleitung von Portalaktionen an die Gruppenverwaltung:

- Der gültige Einstiegsdialog akzeptiert jetzt die interne Portalaktion, ohne dafür ein zusätzliches sichtbares Einstellfeld anzulegen.
- **Gruppe anlegen**, **Gruppe bearbeiten**, **Gruppe entfernen** und der Gruppen-Menüpunkt sollen den jeweiligen Dialog öffnen.
- Die Gruppeneinstellungen bleiben im Portal und werden nicht ins Zahnrad-Menü zurückgebracht.

Bitte die vier Einstiege erneut testen. Beim Anlegen und Bearbeiten den Assistenten bis zum Speichern durchlaufen und außerdem das Entfernen einer Testgruppe prüfen.

Dies ist eine Release-Candidate-Version für externe Tests.
