# Battery SmartFlow AI 5.1.0-beta07

This beta fixes history charts that appeared empty despite Home Assistant
having recorded sensor states, and tones down the hover/focus effect on
clickable dashboard readings.

## Changes

- Parse Home Assistant's entity-keyed history response, including its compact
  state and timestamp fields, while retaining compatibility with array-based
  response shapes.
- Remove the animated-looking hover ring from clickable readings; keyboard
  focus remains visibly indicated without a pulsing effect.
- Bump the dashboard asset version to 1.0.8 to force clients to load the fix.

## Testing focus

Please open history charts for sensors with known Recorder data and verify that
the hour, day, week, and month ranges render values. Also verify that hovering
over a reading no longer produces a pulsing ring and that keyboard navigation
still provides a clear focus indicator.
