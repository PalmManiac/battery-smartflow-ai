# Battery SmartFlow AI 5.1.0-beta03

## Dashboard interaction refinements

- Fixed hardware detail popups so they remain open after clicking, even while Home Assistant updates sensor states.
- Removed hover-only popup behavior that caused flicker and prevented reliable interaction.
- Shortened hardware telemetry labels by removing repeated device and battery-pack names.
- Removed technical sensor names from the bottom of dashboard value cards.
- Shortened control labels by removing the repeated Battery SmartFlow AI prefix.
- Moved the current electricity price out of the wide energy overview and kept it with the other price metrics.
