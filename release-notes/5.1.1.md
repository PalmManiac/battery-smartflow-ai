# Battery SmartFlow AI 5.1.1

Battery SmartFlow AI 5.1.1 adds an optional direct local grid-power source for
the Shelly Pro 3EM Gen2 and improves diagnostics for duplicate Zendure cloud
device entries during setup.

## Highlights

- Added direct local HTTP-RPC metering for the Shelly Pro 3EM Gen2. BSFAI can
  read signed grid power independently of Home Assistant's Shelly integration,
  its `aioshelly` client, and Shelly Cloud. Optional Shelly device-password
  authentication is supported. The regulation cadence is unchanged.
- Improved the duplicate Zendure device-identity diagnostic. When duplicate
  entries are returned, BSFAI now compares them internally and logs whether
  their records are identical, plus safe field names that differ. It does not
  log identifier, serial-number, device-name, IP-address, or field values.
  Setup continues to fail safely on duplicate identities; automatic
  deduplication is not performed.
- Added regression coverage for exact duplicate records and verified that
  diagnostic output does not expose device or account values.
