# V6.0.0-dev1.01: Communication path reporting fix

This test build corrects how the native device overview reports each system's configured and selected communication path. When native control is disabled, the overview now reports the configured per-device path instead of falling back to the transport identity used when the device was discovered. If control is active, it reports the active control path.
