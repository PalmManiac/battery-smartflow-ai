# Battery SmartFlow AI 5.1.0.1

This patch improves diagnostics for a failed native Zendure setup when the
cloud device list contains duplicate identities.

- Added a privacy-safe Home Assistant warning that identifies the duplicate
  device-list positions, model names, and identity field type. Device IDs,
  serial numbers, device names, and credentials are not logged.
- Added regression coverage to ensure the duplicate-identity warning does not
  expose identifiers, names, or token material.
