# V6.0.0-dev1.7: Per-system battery protection and full-charge maintenance

This dev1.7 test build includes PR #842. Cell-voltage monitoring and emergency charging can now evaluate each recognized system independently, including when optional cell-voltage protection is disabled. Full-charge maintenance also makes its decisions per system and directs control commands to the intended configured device. Supported and fully configured systems can be controlled; unsupported or incomplete systems remain read-only.

## External field tests requested

- With at least two recognized systems, verify that battery and cell-voltage sensors remain available for every system, both with cell-voltage protection disabled and enabled, including after a Home Assistant restart.
- If safe to reproduce, confirm a cell-voltage protection response is associated with the system whose cell voltage triggered it. Please include timestamps and diagnostics; do not force unsafe battery conditions for testing.
- Verify that full-charge maintenance evaluates each supported, fully configured system separately. Report whether a maintenance request for one system leaves the other systems' state and commands unaffected.
- Confirm unsupported or incompletely configured systems remain visible as read-only and receive no control commands.
- Recheck house-load calculation while charging, discharging, importing from the grid, and exporting to the grid. Include a screenshot and current PV, grid, battery, and house-load entity states if the value is incorrect.
- Include the BSFAI version and relevant diagnostics, with credentials, App-Tokens, and private system details removed.

Please report both successful and failed cases in the V6 test discussion. We will review external multi-system test results and logs before starting the next issue or development stage.
