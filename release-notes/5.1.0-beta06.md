# Battery SmartFlow AI 5.1.0-beta06

This beta adds interactive sensor history to the optional HEMS dashboard and
makes the dashboard easier to leave on mobile devices.

## Changes

- Make dashboard readings, energy-flow values, and system signals open a
  matching history chart when selected.
- Add hour, day, week, and month ranges. Live measurements are drawn as a line;
  energy counters show increases per interval. The chart uses states already
  recorded by Home Assistant and reports when history is unavailable.
- Add a visible Home Assistant navigation link in the dashboard header so users
  can leave the standalone panel even when the sidebar is hidden, including on
  an iPhone in portrait orientation.

## Testing focus

Please test chart navigation and date ranges on desktop and mobile, especially
on an iPhone in portrait mode. Confirm that sensors with Recorder history show
the expected curve or energy increments, and that sensors without recorded
history display a clear message. Verify that the Home Assistant link returns
to the main interface.
