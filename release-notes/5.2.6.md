# Retired Zendure battery-pack identities

This maintenance release improves reconciliation of the native Zendure battery inventory. A complete `properties/report` now retires pack identities that are no longer listed, while partial state updates continue to preserve the known pack membership. The same complete inventory is applied across native data sources so an old cached identity cannot reappear in the fused pack list.

## Fixes

- Remove retired battery-pack identities from the native inventory after a complete report. ([PR #813](https://github.com/PalmManiac/battery-smartflow-ai/pull/813))

Restart Home Assistant after installing the update.
