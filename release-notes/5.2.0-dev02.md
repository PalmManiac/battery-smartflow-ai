# Faster, smoother grid response with shadow diagnostics

## Regulation response

- Poll configured Shelly grid meters independently at one-second intervals and react to relevant fresh grid changes without waiting for the regular coordinator cycle.
- Smooth ordinary corrections near the target and apply a bounded fast attack to larger deviations, while preserving existing device and profile power limits.
- Stop the unused Zendure Cloud MQTT path when ZenSDK is selected.

## Measurement and profile groundwork

- Record fresh-telemetry feedforward candidates for comparison; these shadow values do not alter active control targets or send commands.
- Define device-, transport-, model-, and firmware-specific regulation profile data, with charge and discharge kept separate and profiles remaining in shadow state.
- Use native command feedback in control diagnostics when available.
