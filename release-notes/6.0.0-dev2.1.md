# Prevent learned charging during discharge price windows

This development update prevents learned AC charging plans from starting grid charging while the current electricity price is high enough for battery discharge. It also prevents a charge command from being sent during the same control cycle in which a price conflict aborts an active charging commitment.

## External field tests requested

- When a learned AC charging window is active or reaches its latest start time, confirm the battery does not begin charging from the grid while the current price is above the configured discharge threshold.
- Confirm price-based discharge can still start during those expensive price periods.
- Check that learned charging still starts when the price falls into an eligible charging window.
- If charging starts unexpectedly, stops unexpectedly, or oscillates between charging and discharging, report the approximate time, price, decision reason, and sanitized diagnostics.
