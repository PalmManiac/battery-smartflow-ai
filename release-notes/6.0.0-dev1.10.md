# Native multi-hub reconfiguration field test

V6.0.0-dev1.10 moves native Zendure setup and rediscovery into the integration's **Reconfigure** action. The separate **Native Zendure** item has been removed from the gear menu. This release prepares external validation of the unified reconfiguration flow.

## External field tests requested

- On an existing native entry, open the three-dot menu and choose **Reconfigure**. Confirm the general settings step is available and the flow then discovers supported Zendure hubs.
- Confirm discovery offers every supported hub in the installation, including hubs that were already configured, so each can be reviewed and reconfigured individually.
- For each hub, confirm its saved transport, fixed IP (where applicable), and masked App Token are prefilled and retained when left unchanged. Complete the flow and verify the integration reloads successfully.
- Check that devices and sensors for all configured hubs appear in Home Assistant and the portal after reconfiguration. Include the case where an additional battery pack was recently added.
- Confirm price, PV, grid, Shelly, strategy, and learned state remain intact after reconfiguration.
- Confirm **Native Zendure** is no longer listed as a separate gear-menu setting.
- Report the exact BSFAI version, Home Assistant version, hub models, steps, screenshots, and sanitized diagnostics. Remove App Tokens, credentials, and private system details from logs.

We will review external reports and logs before starting the next development stage.
