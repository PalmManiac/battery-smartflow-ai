# Battery SmartFlow AI 5.1.0-beta02

## Dashboard refinements

- Fixed dashboard readings by resolving BSFAI sensors through Home Assistant's entity registry instead of relying on translated display names.
- Added direct support for the configured current electricity-price sensor.
- Limited displayed energy values to three decimal places and monetary values to two.
- Replaced raw entity IDs in dashboard reading captions with a friendly name or a generic Home Assistant sensor label.
- Added integration and dashboard version labels to the dashboard header.
- Improved dashboard tab feedback and coalesced redundant redraws to make navigation feel more responsive.
