# V6.0.0-dev9.2 – Gruppenassistent im Dialog laden

Diese Testversion verbessert das Öffnen der Gruppen-Einrichtung im Portal:

- Während der Gruppenassistent geladen wird, zeigt das Portal einen klaren Ladehinweis im Dialog.
- Wenn Home Assistant den Optionsflow nicht starten kann, wird der leere Dialog geschlossen und der Fehler angezeigt.
- Ein verspäteter Flow wird verworfen, wenn der Dialog während des Ladens geschlossen wurde.

Bitte das Anlegen und Bearbeiten von Gruppen erneut testen. Besonders wichtig sind das Verhalten direkt nach dem Klick, das Öffnen des ersten Schritts sowie ein Abbruch während des Ladens. Die Konfiguration wird erst beim letzten Schritt gespeichert.

Dies ist eine Entwicklungsversion für externe Tests.
