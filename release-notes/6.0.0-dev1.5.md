# V6.0.0-dev1.5: Cell-voltage sensors and multi-system house load

This dev1.5 test build includes the merged fixes from PRs #837 and #838. It stabilizes Hyper 2000 pack inventory, keeps native cell-voltage monitoring available when the optional cell-voltage protection feature is enabled, and calculates combined battery power and house load from fresh measurements across discovered systems where the required readings are complete.

## External field tests requested

- Upgrade to dev1.5 and check that all expected battery and cell-voltage sensors remain visible with cell-voltage protection both disabled and enabled. Please report your battery/system models and whether the native cell-voltage values remain available after restarting Home Assistant.
- Check the energy dashboard house-load value while charging, discharging, importing from the grid, and exporting to the grid. Compare it with the configured grid, PV, and battery sensor values and attach a screenshot plus the relevant current entity states if it is still incorrect.
- Confirm the Hyper 2000 pack inventory remains stable after a Home Assistant restart.
- Include the BSFAI version and relevant diagnostic logs, but remove credentials, App-Tokens, and private system details before posting.

Please report each result, including cases that work as expected, in the V6 test discussion so the fixes can be validated across different installations before the next development stage.
