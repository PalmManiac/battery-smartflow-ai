# Lokalisierte Phasenbezeichnung

Die elektrische Topologie zeigt die unbekannte Phase in der Auswahl jetzt als „Unbekannt“ in der jeweiligen Sprache an. Der gespeicherte technische Wert bleibt unverändert.
