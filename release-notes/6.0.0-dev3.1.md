# Optional Export Price in EnergyScope Setup

This development update fixes EnergyScope setup in the portal when no export price sensor is configured. Blank optional entity selectors are omitted from the submitted form, so a feed-in price sensor is no longer required to complete setup. The HEMS dashboard cache version has also been updated so browsers load the corrected form.

## External field tests requested

- Create an EnergyScope without selecting an export price sensor. Confirm setup completes and the scope can be saved.
- Edit an existing scope without an export price sensor and confirm it can be saved.
- If an export price sensor is available, select it and confirm that the configured value is retained.
- Check the EnergyScope grid, PV, forecast, and group assignments after saving.
- If setup still fails, report the Home Assistant version, browser/device, screenshot of the form and error, and a sanitized diagnostic log.
