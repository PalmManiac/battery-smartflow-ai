# Dashboard training controls and direct configuration access

- Add dashboard controls to start and stop passive regulation training for each loaded BSFAI instance.
- Choose the training duration and whether to capture charging, discharging, or both; the default is 24 hours.
- Show training status, collected samples, and the latest shadow evaluation in the dashboard.
- Add direct access to the Home Assistant integration configuration from the dashboard.
- Keep training observational: learned candidates are not applied to live regulation.
