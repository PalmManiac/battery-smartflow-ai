# Trace Zendure connectivity and HEMS status changes

This test build adds privacy-safe native runtime status samples to debug recordings. The samples help identify why a system changes between online, offline, and HEMS-blocked states. This is a diagnostic build; it does not change control behavior or weaken the existing fail-closed safety checks.

## External field tests requested

- Install this build and enable a debug recording if the system again switches between Offline and “Durch HEMS blockiert”. Keep the recording running through at least one status change, then export it.
- Note the approximate local time of each change and whether the HEMS integration is installed or configured. Do not change HEMS or battery-control settings just to trigger the issue.
- If the status remains stable, report that too, including how long it was observed and the selected transport.
- Report the BSFAI and Home Assistant versions and include the exported debug recording. Remove App Tokens, serial numbers, network addresses, and other private identifiers from screenshots or additional logs.

We will review the external recording before advancing to the next development issue.
