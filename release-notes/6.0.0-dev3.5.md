# Easier Sensor Assignment in the Portal

The sensor assignment editor now shows localized measurement modes and searchable sensor lists. Multiple sensors and groups can be selected individually. The layout is easier to use on desktop and mobile, and live dashboard updates preserve unsaved entries.

- Check the optional import and export price selectors, including leaving them empty and clearing an existing selection.
