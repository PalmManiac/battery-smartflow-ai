# V6.0.0-rc3 – Fehler beim Öffnen der Gruppendialoge sichtbar machen

Diese Release Candidate verbessert die Rückmeldung beim Öffnen der Portal-Konfiguration:

- Gruppen- und andere Optionsdialoge bleiben bei einem Startfehler sichtbar.
- Die konkrete technische Fehlermeldung wird im Dialog angezeigt, statt ihn kommentarlos zu schließen.
- Die Dashboard-Version wurde erhöht, damit Home Assistant die aktualisierte Portal-Datei lädt.

Bitte die Aktionen **Gruppe anlegen**, **Gruppe bearbeiten** und **Gruppe entfernen** erneut öffnen. Falls ein Dialog nicht startet, notiere bitte die angezeigte technische Meldung und hänge sie an die Rückmeldung an.

Dies ist eine Release-Candidate-Version für externe Tests.
