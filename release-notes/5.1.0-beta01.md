# Battery SmartFlow AI 5.1.0-beta01

The first public test build of the new optional HEMS dashboard and the V5.1
planning and economics improvements.

## Highlights

- Added an optional standalone HEMS dashboard with energy-flow, forecast,
  economics, controls and Zendure hardware views. The hardware view groups
  systems and battery packs and exposes useful telemetry on hover/focus.
- Added native PV self-consumption return and weighted average battery charge
  price sensors. The weighted value accounts for grid charging costs and the
  opportunity value of PV energy stored in the battery; the existing grid-only
  average remains separately available.
- Improved PV-aware price planning. Forecasted usable PV surplus now reduces
  planned AC top-up energy conservatively, and an active PV-house-load
  passthrough no longer masks a learned charge that must start before its price
  deadline. The HEMS dashboard explains the estimated forecast credit and
  planned coverage end without adding high-churn diagnostic recorder sensors.
- Learned plans before a price peak now size the battery target for the
  contiguous peak period, while retaining the charge deadline before the first
  peak interval.
- Corrected interval-based "remaining today" PV forecast totals so elapsed
  intervals are not counted again.
- Clarified the older SoC-derived average charge-price entity as a legacy
  estimate; the economics dashboard focuses on the newer energy-and-cost-book
  calculation that also accounts for PV energy stored in the battery.
- Added an EDF Tempo template-sensor example to the German and English guides.
  Unknown or unpublished prices are omitted instead of being treated as free.

## Testing focus

Please pay particular attention to forecast-aware charging before a tariff
peak, PV-house-load passthrough handover, and whether the new dashboard values
match the corresponding Home Assistant entities. Forecast-based planning is
deliberately conservative and depends on the quality and timing of the selected
forecast source.

The French-language guide is not part of this beta and will be prepared later.
