# V6.0.0-dev1.6: Confirmed grouped battery inventory changes

This dev1.6 test build includes PR #840 on top of the dev1.5 fixes. For grouped legacy Zendure models, pack additions, removals, and identity replacements are now applied only after the same complete pack inventory is reported twice in a row. Unconfirmed pack IDs stay out of the visible inventory, preventing transient reports from making the battery topology flicker.

The release also includes the dev1.5 fixes for native cell-voltage sensors with optional cell-voltage protection enabled, multi-system battery power and house-load calculations, and Hyper 2000 pack inventory stability.
