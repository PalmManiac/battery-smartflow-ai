# Reliable portal battery group management

This development update fixes the Battery Groups portal editor so it opens from the group view. Group selection also distinguishes systems with the same model by serial suffix, or by a short stable identifier when serial data is unavailable.

## External field tests requested

- Open Battery Groups in the portal and press **Manage groups**. Confirm the group editor appears without switching to the gear menu.
- Create, edit, and remove a group from the portal, then confirm the saved memberships and names persist after leaving and reopening the view.
- If multiple systems with the same model are available, confirm each one is distinguishable in the selection list by its serial suffix or short identifier.
- Confirm the existing gear-menu group editor still opens and both interfaces show the same group memberships.
- Report any button that does not open the editor, missing or duplicated systems, or groups that fail to save. Include a screenshot with private identifiers removed.
