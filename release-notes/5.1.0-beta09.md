# Battery SmartFlow AI 5.1.0-beta09

This beta fixes the dashboard's week and month history charts.

## Changes

- Interpret Home Assistant Recorder statistics timestamps as epoch
  milliseconds so historical samples are placed inside the selected chart
  range.
- Calculate chart scales from the selected historical data instead of mixing
  in the changing live sensor value.
- Bump the dashboard asset version to 1.0.11 and refresh its cache key.

## Testing focus

Please verify that week and month charts show historical values and that their
axis labels and summary values remain stable while live sensors continue to
update.
