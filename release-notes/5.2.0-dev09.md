# Clearer power limits and steadier ZenSDK telemetry

- Set configurable charge and discharge limits to the selected device model's supported maximum, and present them as numeric inputs.
- Reduce unnecessary Home Assistant Recorder updates while keeping the complete device overview in diagnostics.
- Make clickable dashboard sensor cards visibly glow in their resting state, with stronger hover and keyboard-focus feedback.
- Apply ZenSDK retry delays after slow requests finish to avoid immediate repeated polling after timeouts.
