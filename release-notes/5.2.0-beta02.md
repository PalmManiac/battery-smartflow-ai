# Clearer energy tiles and steadier Shelly readings

This update refines the energy overview and makes Shelly Pro 3EM readings more tolerant of slower responses.

## Dashboard

- Add large, subtle watermark icons to the energy overview cards, tinted to match each tile and enhanced with a soft glow.
- Give grid power, import, and export a distinct red accent.

## Shelly Pro 3EM

- Increase the local HTTP and Modbus TCP request timeout from 1.5 to 3 seconds while keeping the independent one-second polling cadence and in-progress guard unchanged.

This is a beta release. Please continue to monitor regulation and communication stability after updating.
