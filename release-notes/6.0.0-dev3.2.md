# Clearer Battery Charge Price Sensor Names

This update clarifies the two average battery charge price sensor names. The lifetime weighted value is now labeled as the total charge price (grid + PV), while the SoC-based estimate is labeled as the current estimated charge price. Calculations and sensor entity IDs are unchanged.

## External field tests requested

- Confirm Home Assistant shows `Ø Ladepreis gesamt (Netz + PV)` and `Ø Ladepreis aktuell (geschätzt)`.
- Confirm the HEMS portal shows the total value as `Ø Ladepreis gesamt (Netz + PV)`.
- Check that the existing sensor values remain available and their history/entity IDs are preserved after the name update.
- Confirm that the labels distinguish the overall Economics balance from the current SoC-based estimate.
- Report unexpected value changes, missing sensors, or entity ID changes with screenshots and a sanitized diagnostic log.
