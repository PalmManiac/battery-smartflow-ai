# Battery SmartFlow AI 5.1.0-beta05

This beta continues the V5.1 HEMS dashboard rollout with clearer forecast
readings, a cleaner system overview, and refinements from the first beta tests.

## Highlights since beta01

- Added an optional standalone HEMS dashboard with energy-flow, forecast,
  economics, controls and Zendure hardware views. The hardware view groups
  systems and battery packs and exposes useful telemetry in detail popups.
- Added native PV self-consumption return and weighted average battery charge
  price sensors. The weighted value accounts for grid charging costs and the
  opportunity value of PV energy stored in the battery.
- Improved PV-aware price planning. Forecasted usable PV surplus now reduces
  planned AC top-up energy conservatively, and an active PV-house-load
  passthrough no longer masks a learned charge that must start before its price
  deadline.
- Corrected interval-based "remaining today" PV forecast totals so elapsed
  intervals are not counted again.
- Added an EDF Tempo template-sensor example to the German and English guides.
- Fixed dashboard readings by resolving BSFAI sensors through Home Assistant's
  entity registry, added the configured current electricity-price sensor, and
  limited energy and monetary display precision.
- Added integration and dashboard version labels, removed technical entity IDs
  from value cards, shortened repeated prefixes, and improved navigation and
  hardware detail interactions.
- Simplified the System Signals section to additional BSFAI status and diagnostic
  sensors; controls and hardware telemetry already available in their dedicated
  views are no longer repeated. Long values remain readable instead of being
  clipped.
- Fixed solar forecast readings for translated Home Assistant entity names by
  resolving forecast sensors through their registered unique IDs. This keeps
  the display compatible with providers such as Helios Forecast using HA's
  standard Energy forecast interface.

## Testing focus

Please verify that forecast values are displayed for the selected Home
Assistant Energy forecast integration and that System Signals contains only
additional status/diagnostic readings without duplicating controls or hardware
details. Forecast-based planning remains conservative and depends on the
selected provider's data and update timing.
