# V6.0.0-rc5 – Gruppenaktionen über einen gültigen Optionsflow-Einstieg öffnen

Diese Release Candidate korrigiert den Start der Gruppenaktionen im Portal:

- Home Assistant erlaubt beim Menüschritt nur die angebotenen Optionsflow-Einstiege. Die Gruppenaktionen werden deshalb über einen gültigen Einstieg an den passenden Gruppenassistenten weitergeleitet.
- **Gruppe anlegen**, **Gruppe bearbeiten**, **Gruppe entfernen** und der Gruppen-Menüpunkt im Portal öffnen den vorgesehenen Schritt.
- Die Gruppeneinstellungen bleiben im Portal gebündelt und werden nicht als zusätzlicher Punkt im Zahnrad-Menü eingeblendet.

Bitte alle vier Einstiege testen. Beim Anlegen und Bearbeiten den Assistenten bis zum Speichern durchlaufen; außerdem das Entfernen einer Testgruppe prüfen.

Dies ist eine Release-Candidate-Version für externe Tests.
