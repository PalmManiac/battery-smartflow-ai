# Battery SmartFlow AI 5.1.0

Battery SmartFlow AI 5.1.0 delivers the new optional HEMS Portal, V5.1 energy
and economics improvements, expanded Zendure model recognition, and the manual
PV-surplus charging action.

## Highlights

- Added an optional standalone HEMS portal with energy overview and flows,
  forecasts, economics, controls, system signals, and a Zendure hardware
  topology view. Battery-pack cards visualize live state of charge with a
  left-to-right fill framed by a full 2 px outline.
- Added interactive history charts for dashboard readings, with hour, day,
  week, and month ranges, plus a Home Assistant navigation link for mobile
  users.
- Improved dashboard sensor resolution, forecast source selection, labels,
  numeric precision, navigation responsiveness, and history rendering. The
  portal uses Home Assistant's Energy forecast interface, including compatible
  providers such as Helios Forecast, rather than assuming Solcast.
- Kept System Signals focused on additional status and diagnostic entities,
  avoiding duplicate controls and hardware telemetry already available in
  dedicated views.
- Added native PV self-consumption return and weighted average battery charge
  price sensors. The weighted value accounts for grid charging costs and the
  opportunity value of stored PV energy while preserving the separate grid-only
  average.
- Improved PV-aware price planning: usable forecast surplus reduces planned AC
  top-up energy conservatively, remaining-today forecast totals exclude elapsed
  intervals, and learned pre-peak plans size the target for the contiguous peak
  period while respecting its charge deadline.
- Added the manual **PV Surplus Charging** action. It uses the configured
  export threshold, stable confirmation, and ongoing power adjustment; it does
  not fall back to grid charging when confirmed PV surplus is unavailable.
- Economic and effective discharge thresholds now prefer the weighted battery
  charge price, retaining the previous estimate as a fallback.
- Recognized the original SolarFlow 800 and SolarFlow 1600 AC+ as ZenSDK device
  models. Unverified write commands remain safely unavailable.
- Improved price-per-energy unit symbols while retaining ISO currency codes
  for monetary values, and refined dashboard display precision.
- Added an EDF Tempo template-sensor example to the German and English guides;
  unknown or unpublished tariff prices are omitted rather than treated as free.

## Upgrade notes

The HEMS portal is optional and can be enabled from the integration's settings.
Forecast-based planning depends on the selected provider's data and update
timing. The French-language guide is planned separately.
