# V6.0.0-dev5.4 – Faster Zendure telemetry and regulation refresh

## Changes

- Reduce the ZenSDK device telemetry polling interval from 5 to 3 seconds.
- Reduce the minimum interval for coalesced grid-event regulation refreshes from 5 to 3 seconds.
- Keep the regular 10-second coordinator cycle as a fallback and preserve retry backoff for failed ZenSDK polls.
- Bump the integration version to `6.0.0-dev5.4`.

## Please test

- Update and reload the integration, then confirm ZenSDK telemetry and control remain healthy.
- During changing household loads, compare how quickly grid power and battery power respond with the previous release.
- Watch for repeated, delayed, or skipped commands, stale readings, increased device/network load, and any loss of control.
- Multi-system users: confirm the faster polling works for every configured ZenSDK device without one device delaying the others.
- Report the installed version, device model(s), selected transport, a short event timeline, and a Debug export if behavior is unexpected.
