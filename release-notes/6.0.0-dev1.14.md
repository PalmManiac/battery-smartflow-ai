# Native Zendure control can be enabled again

This test build restores the native Zendure setup in the Home Assistant options menu and makes the control approval switch available during setup and reconfiguration. The chosen switch state is now saved instead of the reconfigure flow silently retaining the previous disabled state.

## External field tests requested

- Open the integration options and confirm that **Natives Zendure** is available.
- Select the existing supported system and ZenSDK, enable native control, and save. Confirm the native control status changes from disabled to ZenSDK once the transport is ready.
- Disable native control again and confirm the status returns to disabled; then re-enable it and confirm the setting survives an integration reload or Home Assistant restart.
- Verify that the selected battery receives the expected BSFAI control action and that the integration reports no native command error.
- Report the BSFAI version, Home Assistant version, selected transport, native control status, and the resulting action. Remove App Tokens, IP addresses, serial numbers, and other private identifiers from screenshots and logs.

We will review external reports before moving on from this dev1 test stage.
